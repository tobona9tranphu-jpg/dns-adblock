📋 Hướng Dẫn Cài Đặt

Chỉ 4 bước đơn giản, hoàn thành trong 1 phút.

1

Mở bằng Safari

Truy cập trang này bằng Safari trên iPhone/iPad. Các trình duyệt khác (Chrome, Firefox) không hỗ trợ cài profile.

2

Tải Profile

Nhấn nút "⬇️ Tải Profile DNS" ở trên. Safari sẽ hỏi "Trang web này muốn tải cấu hình" → nhấn Cho phép.

3

Cài đặt Profile

Mở Cài đặt (Settings) → nhấn "Đã tải về Profile" ở đầu trang → nhấn Cài đặt (Install) → nhập mật khẩu.

4

Hoàn tất! 🎉

Quảng cáo bị chặn ngay lập tức. Kiểm tra tại adguard.com/test.html

🔐 Bảo Mật & An Toàn

Profile này được thiết kế với tiêu chí an toàn tối đa.

  • ✅
    Không Root CA Certificate — Profile không cài bất kỳ chứng chỉ nào. Không thể đọc hoặc can thiệp HTTPS.
  • ✅
    Không SSL Interception (MITM) — Kết nối SSL/TLS vẫn mã hóa end-to-end giữa bạn và website.
  • ✅
    Chỉ thay đổi DNS — Không ảnh hưởng VPN, proxy, hay bất kỳ cấu hình mạng nào khác.
  • ✅
    Gỡ bỏ dễ dàng — PayloadRemovalDisallowed = false — xóa profile bất cứ lúc nào trong Cài đặt.
  • ✅
    Mã nguồn mở — Bạn có thể mở file .mobileconfig bằng text editor để kiểm tra toàn bộ nội dung.

🛡️ So sánh: Profile này vs Profile có Root CA

Các profile "VIP/Gold/Premium" thường cài kèm Root CA — cho phép chủ server giải mã toàn bộ HTTPS của bạn (mật khẩu, ngân hàng, tin nhắn). Profile này KHÔNG làm điều đó.

🗑️ Cách Gỡ Profile

Nếu gặp vấn đề, bạn có thể gỡ profile dễ dàng.

📱 iPhone / iPad

  1. Mở Cài đặt (Settings)
  2. Vào Cài đặt chung (General) → VPN & Quản lý thiết bị
  3. Nhấn vào "DNS Ad Blocker - Chan Quang Cao"
  4. Nhấn "Xóa Profile" → nhập mật khẩu

💻 macOS

  1. Mở System Settings → Privacy & Security → Profiles
  2. Chọn profile → nhấn nút "−" → nhập mật khẩu admin
